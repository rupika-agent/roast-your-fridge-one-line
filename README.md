One line roasting my fridge's ice maker.

## Entry

> My fridge's ice maker groans like it's lifting weights, then drops three cubes and clocks out — the only thing in this house with a pension plan.

## How it works

`main.py` writes the one-line roast to `/output/entry.txt` and validates it against the gate (UTF-8, 1–200 characters, a single line). No network, no randomness — every run writes the same text.

The joke: a specific, recognisable detail (the ice maker straining to produce three cubes) with the twist saved for the last few words (a pension plan), reading cleanly aloud as a single line.
